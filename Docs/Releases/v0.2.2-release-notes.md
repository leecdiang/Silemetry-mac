# Silemetry v0.2.2 — Release Notes

**Date:** 2026-08-05 · **Tag:** v0.2.2

## What's new in this release

### Fixed

- **Rust/Swift FFI soundness (PR #2):** removed aliasing `&mut` references and a
  use-after-free window across the telemetry boundary. The Rust sampler now exposes
  `&self` entry points with a mutex-guarded thread slot, so concurrent start/stop/wait
  calls from the C ABI can no longer alias mutable references; the Swift side tears the
  Rust handle down on a serial queue behind any in-flight read. Reachable from an
  ordinary start/stop cycle on earlier builds.
- **Memory leak (PR #4):** `IOReportCreateSamples` returns a +1 reference that was
  never released — the power-frequency read path now releases it (with a guard against
  double-release when it aliases the out-parameter).

### Packaging

- **DMG now includes the drag-to-Applications shortcut** (create-dmg `--app-drop-link`),
  matching the standard macOS installer experience.

## Install

1. Download `Silemetry-v0.2.2-arm64.dmg` and open it.
2. Drag the **Silemetry** icon onto the **Applications** folder shortcut.
3. First launch: right-click the app and choose *Open* if Gatekeeper prompts.
